# Five projects to start with

Install the skills, then paste a brief into your coding assistant. Provide your actual assets, copy and project directory.

## Interactive product launch

```text
/webmaker Build a designer headphone launch page with /webmaker-reactthreefiber
and /webmaker-drei. Use /webmaker-gltfjsx for part-level finish controls and
/webmaker-gltf-transform to inspect the supplied model. Add a clear product story,
bounded orbit controls, a keyboard-accessible reset and a purchase CTA.
Lazy-load 3D behind a poster. Verify mobile, reduced motion and WebGL failure.
```

## Creative studio portfolio

```text
/webmaker Create an editorial studio portfolio. Use /webmaker-shadergradient
for one atmospheric hero, /webmaker-liquidlogo for my supplied brand mark and
/webmaker-liquidglassreact for a small floating navigation surface.
Prioritize typography, case-study browsing, readable contrast and static fallbacks.
```

## Cinematic object study

```text
/webmaker Create a sculptural product story with /webmaker-reactthreefiber
and /webmaker-drei. Add restrained selective bloom using
/webmaker-react-postprocessing. Keep product details sharp, include a low-cost
effects mode and put the accessible narrative in HTML. Measure mobile frame cost.
```

## HTML furniture catalog

```text
/webmaker Add /webmaker-model-viewer to this existing HTML or Astro product page.
Use my GLB, a poster and descriptive alternative text. Offer AR only where
supported. Use /webmaker-gltf-transform to inspect the asset before publishing.
Preserve the original model and the existing site framework.
```

## Continuous 3D portfolio

```text
/webmaker Build a multipage portfolio in my existing Next.js App Router project.
Use /webmaker-react-three-next as a persistent-canvas architecture reference,
with /webmaker-reactthreefiber and /webmaker-drei. Preserve scene state across
routes. Verify client boundaries, direct loads, back/forward, focus and cleanup.
Adapt the pattern to my project's versions instead of copying the older stack.
```

## Add a concrete delivery request

```text
Deliver editable source, a production build result and desktop/mobile screenshots.
Report dependencies added, asset sizes, remaining limitations and checks that
could not run. Do not claim a performance score without measuring it.
```
