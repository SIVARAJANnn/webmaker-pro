# A living identity

**`/webmaker-liquidlogo` — Give a logo a flowing metallic finish.**

![A living identity: AI-generated concept illustration](../assets/webmaker-liquidlogo.png)

*AI-generated concept illustration; not a screenshot or a bundled model.*

## Where and when to use it

In brand introductions, creative portfolios and campaign headers with an existing logo asset.

## How it helps you build

Makes a brand mark a memorable focal point with shader-driven liquid highlights.

## Try this prompt

```text
/webmaker-liquidlogo Animate my supplied logo with subtle liquid-metal highlights. Preserve its silhouette, provide a static logo fallback and pause work when the section is offscreen.
```

## Installation and practical notes

Install the skill using [Step 1](../INSTALLATION.md#step-1--install-the-skills-in-your-favorite-editor), then prepare the toolkit with [Step 2](../INSTALLATION.md#step-2--prepare-all-subpackages-with-one-prompt). Uses bundled JavaScript and GLSL source, not a separate webmaker npm dependency. Avoid making essential branding unreadable.

Pair this with `/webmaker` for the surrounding page, typography and responsive layout. Verify actual rendering, keyboard interaction, reduced motion and the production build on your target devices.
