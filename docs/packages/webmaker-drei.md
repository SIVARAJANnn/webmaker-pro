# Your scene toolkit

**`/webmaker-drei` — Assemble lighting, controls and model helpers.**

![Your scene toolkit: AI-generated concept illustration](../assets/webmaker-drei.png)

## Where and when to use it

Inside an existing React Three Fiber scene when you need common scene utilities.

## How it helps you build

Reduces repeated setup for model loading, orbit controls, environment lighting and presentation.

## Try this prompt

```text
/webmaker-drei Improve my Fiber viewer with Drei model loading, bounded orbit controls, soft lighting and a loading state. Reuse resources and keep mobile rendering affordable.
```

## Installation and practical notes

Install the skill using [Step 1](../INSTALLATION.md#step-1--install-the-skills-in-your-favorite-editor), then prepare the toolkit with [Step 2](../INSTALLATION.md#step-2--prepare-all-subpackages-with-one-prompt). Drei complements Fiber; it is not a standalone renderer. Budget environment maps and shadows.

Pair this with `/webmaker` for the surrounding page, typography and responsive layout. Verify actual rendering, keyboard interaction, reduced motion and the production build on your target devices.
