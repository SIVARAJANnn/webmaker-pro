# Build in three dimensions

**`/webmaker-reactthreefiber` — Create interactive React 3D scenes.**

![Build in three dimensions: AI-generated concept illustration](../assets/webmaker-reactthreefiber.png)

*AI-generated concept illustration; not a screenshot or a bundled model.*

## Where and when to use it

In product explorers, interactive storytelling and custom scene interactions that need more than a basic model embed.

## How it helps you build

Connects Three.js rendering to React components, with controllable cameras, animation and scene state.

## Try this prompt

```text
/webmaker-reactthreefiber Build an interactive product hero using my GLB, with orbit interaction, an accessible reset button, a static poster, lazy loading and reduced-motion support.
```

## Installation and practical notes

Install the skill using [Step 1](../INSTALLATION.md#step-1--install-the-skills-in-your-favorite-editor), then prepare the toolkit with [Step 2](../INSTALLATION.md#step-2--prepare-all-subpackages-with-one-prompt). Match Fiber to the project's React major. Keep content in HTML and one render-loop owner per canvas.

Pair this with `/webmaker` for the surrounding page, typography and responsive layout. Verify actual rendering, keyboard interaction, reduced motion and the production build on your target devices.
