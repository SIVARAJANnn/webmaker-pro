# The creative director

**`/webmaker` — Turn a brief into a cohesive website.**

![The creative director: AI-generated concept illustration](../assets/webmaker.png)

*AI-generated concept illustration; not a screenshot or a bundled model.*

## Where and when to use it

At the beginning of portfolios, studio sites and product launches, or when a redesign needs a clear visual direction.

## How it helps you build

Coordinates concept, typography, layout, motion, responsiveness and visual QA so effects support the story.

## Try this prompt

```text
/webmaker Build an editorial portfolio for an architecture studio. Use bold typography, a restrained palette, an interactive model hero and accessible motion. Preserve the existing framework; implement and visually verify desktop and mobile.
```
